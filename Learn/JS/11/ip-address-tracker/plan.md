## Элементы плана:

1.  Инициализировать сборщик Vite
2.  Закинуть файлы дизайна в проект
3.  Закинуть \_normalize.scss и подключить
4.  Инициализировать шрифты
5.  Сверстать UI
    - Заголовок
      IP Address Tracker
      Поле ввода
    - Вывод информации
      IP Address
      Location
      Timezone
      ISP
    - Карта
    - Фон
6.  Реализовать логику проекта
    - Ознакомиться с API
      - IP: https://geo.ipify.org/
    - Смена класса для формы при фокусе
    - Валидация введенного IP (можно сделать через RegExp / библиотеку для работы с формами)
    - Получение данных по IP
    - Отображение данных
    - Ознакомиться с API
      - Map: https://leafletjs.com/
    - Отображение карты
    - Отображение кастомного маркера
    - Отображение карты по запросу к IP
7.  Дополнительно - Отображение текущего местоположения по IP
    - Добавление класса ошибки на поле ввода (пусто/не IP)
